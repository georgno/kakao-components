Squashy components

Form controls with squash and stretch motion. Vanilla Web Components with Shadow DOM, no dependencies, styled with CSS custom properties.

Install

Each component is one file. Load it with a script tag and use the element anywhere in your markup.

<script src="squashy-switch-group.js"></script>
<script src="squashy-step-switch.js"></script>

Data goes in a JSON list-data attribute. Every option is an attribute, so plain HTML is enough. Methods exist for the same things and the attribute always wins.

Switch group

A set of on/off switches. Drag the thumb with a finger or mouse, or tap and use the keyboard. Pull past an end and the thumb squashes into the wall.

Syntax

<squashy-switch-group label="Notifications" orientation="vertical"
  list-data='[
    {"name":"email","label":"Email","checked":true},
    {"name":"sms","label":"SMS"},
    {"name":"push","label":"Push notifications","checked":true}
  ]'>
</squashy-switch-group>

Horizontal

The default orientation lays the switches in a row and wraps when space runs out.

<squashy-switch-group label="Preferences"
  list-data='[{"name":"dark","label":"Dark mode"}, …]'>
</squashy-switch-group>

Disabled

Disable a single switch with "disabled": true in its data, or the whole group with the disabled attribute. Disabled controls leave the tab order and set aria-disabled.

<squashy-switch-group list-data='[{"name":"b","label":"Not available","disabled":true}]'></squashy-switch-group>
<squashy-switch-group disabled list-data='…'></squashy-switch-group>

Thumb drag

Dragging is on by default. Set thumb-drag="false" to keep taps and the keyboard only.

<squashy-switch-group thumb-drag="false" list-data='…'></squashy-switch-group>

Events

Events bubble and cross the shadow boundary, so one listener on the document is enough.

el.addEventListener('switch-change', (e) => {
  const { name, index, checked } = e.detail;
});

Step switch

One thumb with several positions. It snaps to the nearest step, the label under the thumb swells as it gets close, and each step is a radio button for assistive technology.

Syntax

<squashy-step-switch label="Quality" value="med"
  list-data='[
    {"value":"low","label":"Low"},
    {"value":"med","label":"Medium"},
    {"value":"high","label":"High"}
  ]'>
</squashy-step-switch>

Many steps

Any number of steps works. The track widens as needed so every label stays visible.

<squashy-step-switch label="Playback speed" value="3"
  list-data='[{"value":"1","label":"0.5×"}, … ,{"value":"5","label":"2×"}]'>
</squashy-step-switch>

Disabled steps

A disabled step has no dot, is skipped by the arrow keys and cannot be selected. A drag that ends on it snaps to the nearest enabled step.

{"value":"c","label":"Wed","disabled":true}

Labels and ticks

Hide the dots with show-ticks="false" or the labels with show-labels="false".

<squashy-step-switch show-ticks="false" list-data='…'></squashy-step-switch>
<squashy-step-switch show-labels="false" list-data='["1","2","3","4"]'></squashy-step-switch>

Methods

Everything the attributes do is also available from script.

el.stepBy(1);
el.setValue('boost');
el.addEventListener('step-change', (e) => console.log(e.detail.value));

Theming

Colours, sizes and motion are CSS custom properties, set from outside the shadow root. Every variable is listed in the README at the top of each component file.

Colours

Nothing changes colour by default. These two are examples of what is possible. The step switch only shifts its colour along the track when you add color-shift.

squashy-switch-group {
  --squashy-switch-track-bg-on: #16a34a;
  --squashy-switch-thumb-bg: #fefce8;
  --squashy-switch-anim-duration: 450ms;
}
/* opt in with the color-shift attribute */
squashy-step-switch {
  --squashy-step-switch-track-bg-off: #fbbf24;
  --squashy-step-switch-track-bg-on: #dc2626;
}

Size

squashy-step-switch {
  --squashy-step-switch-track-height: 2.25rem;
  --squashy-step-switch-thumb-size: 1.8rem;
}
