Settings

The look of these pages. The theme is the only setting that is stored; it applies to every page, because every page reads the same colour variables.

Theme

Pick one of the themes from shared/themes.css. The thumb and the menu follow the pointer, and both cross-fade the page.

Now: — · —

A choice is remembered in this browser (localStorage, key kakao-theme). “Follow the system” forgets it: the pages then follow the operating system's light or dark setting.

Component settings

Every component's look is a set of --kakao-<component>-* custom properties. Each has a construction page that previews it live and edits those values; the shared colour and size variables sit on one page.

Editing needs the construction server: node tools/construct-server.js, then open a construction page from http://localhost:8790. Without it the pages still preview, but saving is disabled.

Other ways to look around

The style guide explains the rules the components follow, the main variables page holds the shared values, and the kitchen sink shows the components together in a real form.

Themes live in shared/themes.css and must pass node tools/check-themes.js (WCAG 2.2 AA). Pickers are described in the header of components/theme-switch/theme-switch.js.
