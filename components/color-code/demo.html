Color code

<kakao-color-code> - a colour value as a small label, with a swatch of the colour before it. The text is the colour; value paints a different one. Any CSS colour works. Try the theme switch.

Syntaxes

Hex · 3, 4, 6 and 8 digits

#f80 #f808 #4f46e5 #4f46e580

Functions

rgb(220 38 38) rgba(0, 0, 0, .3) hsl(160 84% 39%) hsla(262, 83%, 58%, .5) hwb(30 10% 20%) lab(52% 40 59) lch(52% 72 56) oklab(0.6 -0.1 0.1) oklch(70% 0.15 145) color(display-p3 1 0.5 0) color-mix(in oklch, #4f46e5 40%, white)

In text

The primary colour #4f46e5 is 6.3:1 on white; dark uses #818cf8. It sits on the line like a code span.
