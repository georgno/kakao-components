Number input

<kakao-number-input> - wraps a native <input type="number"> with custom stepper arrows; scroll the wheel over the arrows to step. Light DOM: load number-input.css next to the script.

Variants

min, max, step, value and disabled stay on the inner input.

Default

Small · step 0.5

Touch layout · touch-steppers

Used automatically on touch screens: − and + as 44px buttons in one joined pair; hold to repeat.

Pair on the left · group-position="left"

Split · grouped="false" plus="left"

+ on the left, − on the right, as two separate buttons.

One button · minus="false"

Disabled

Playground

Changes bubble as normal input / change events from the inner input.

Attributes on the host: size (sm), touch-steppers, plus / minus (left · right · false), grouped (default on, false = separate), group-position (left · right). Everything else lives on the wrapped input. Full reference in the header of number-input.js.
