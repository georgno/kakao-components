Theme switch

<kakao-theme-switch> — switches the page between colour themes: light, dark and Catppuccin. The new theme spreads from the button as a ripple. The choice is remembered; until then the page follows the operating system.

Variants

All switches on a page stay in sync, also across tabs.

Icon only

With label · show-label

Disabled

Dropdown · kakao-button menu

Picks any theme, also ones the switch doesn't cycle through. The ripple starts at the picked item.

Themed components

Accessibility

Every theme has to pass node tools/check-themes.js: text 4.5:1, borders, focus and filled controls 3:1.

With reduce motion turned on in the system, the theme changes at once, without the ripple or the icon morph. Keyboard activation starts the ripple at the button. A polite live region announces the new theme. With the system's increase contrast setting, muted text and borders get stronger in every theme.
