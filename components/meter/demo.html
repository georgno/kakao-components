Meter

<kakao-meter> - a gauge, like native <meter>: a value within a known range. The fill colour says whether the value is good, so-so or bad, from low, high and optimum.

Storage · lower is better

max="100" low="30" high="80" optimum="20": the optimum sits below low, so up to 30 GB is good, up to 80 GB so-so, above that bad.

Step through it

Walk the value through the regions: the fill slides, and its colour switches as it enters a new region.

Where the optimum lies · optimum

Same range (low="0.3" high="0.7"), same value 0.85, three optimums. With the optimum between low and high, values outside are only so-so, never bad (as on native).

Sizes · size

No visible label: name it with aria-label.

Attributes: value (default 0), min (default 0), max (default 1), low, high, optimum, label, show-value, value-text, size (sm · md · lg). Properties: the same numbers, plus read-only position and region. Full reference in the header of meter.js.
