Aside menu

<kakao-aside-menu> — a completely hidden slide-in menu. The built-in hamburger button pushes the whole page aside and slides the panel into the freed space; a close button in the panel header closes it again. Light DOM: load aside-menu.css next to the script.

Try it

The menu below is a normal site menu. Open it and watch the page — including this text and the theme switch — slide to the right.

Home Browse My list Downloads Settings Sign out

Any markup placed inside the element is shown in the menu.

Attributes on the host: label, position (left · right), width (any CSS length), open, no-open-button, list-data, selected. Methods: open(), close(), toggle(). Escape closes, focus is trapped inside the open panel and returned to the trigger. Full reference in the header of aside-menu.js.
