Code input

<kakao-code-input> - A one-time code or PIN: one box per character, 4 to 8 of them. Typing moves on, Backspace goes back, a pasted or SMS-autofilled code fills every box. One real field lies over the drawn boxes, so autofill, paste and screen readers meet a normal text field. Form-associated.
