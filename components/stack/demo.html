Stack

<kakao-stack> - a pile of cards: the newest child in front, the older ones behind it, each a little smaller, paler and tilted back. Point at the pile or tab into it and the cards fan out into a list. It is also the scaffold other components extend: the toast is a stack of alerts with timers and a live region.

Inline · in the page flow

Without position the stack sits in the page and its cards peek out below the front one. Any element child is a card; the last child is the newest. dismiss(card) lets a card shrink away and removes it, appending a card slides it in at the front.

Corner · position

bottom-right, bottom-left, top-right, top-left fix the stack to that corner of the viewport, as the toast does: safe-area insets, below the header bar in top corners, beside an aside menu on its side. In bottom corners the cards peek out above the front one, and dismissed cards slide out towards the edge.

Extending · KakaoStack

A component that needs the pile extends KakaoStack instead of copying it: it gets the layout, fanning, max, the enter and leave motion and the corner placement, and adds its own behaviour through hooks. The full list is in the header of stack.js; toast.js is the worked example.

class UploadPile extends KakaoStack {
  // Its own settings replace the stack's (same --_* names).
  static get stackStyles() { return `:host { --_width: var(--kakao-upload-pile-width, 18rem); }`; }
  _isItem(el) { return el.localName === 'kakao-card'; }       // which children are cards
  _itemAdded(rec) { super._itemAdded(rec); startUpload(rec.el); }
  _updated() { /* rec.index and rec.visible are current: run timers here */ }
  _fade(rec, paler) { /* paint a card behind the front one */ }
}
customElements.define('kakao-upload-pile', UploadPile);
Attributes: position, max, label, expanded (set by the stack). Properties: max, expanded, items. Method: dismiss(el, reason). Events: stack-add, stack-removed (with reason), stack-expand. Full reference in the header of stack.js.
