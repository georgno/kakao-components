Kbd

<kakao-kbd> - keyboard keys as keycaps: a key, a combination or a sequence. Inline and not interactive; drawn the way the reader's platform writes them.

Keys

Single keys

The text is the key. Anything that is not a known key name is shown as written.

Esc K F5 Space ?

Combination · +

A plus joins the keys of one combination, in the text or in keys. Here with platform="other", so it looks the same on every machine.

Ctrl+K

Sequence · a space

A space separates keys pressed one after the other. then-label sets the word between them.

Arrows

Arrow keys are drawn as arrows on every platform; a screen reader hears "Up arrow".

Platform

Detected · Mod

Mod is Command on a Mac and Ctrl everywhere else. Without platform the component asks the browser, so these follow the machine you are on.

Mac · platform="mac"

Modifiers, Return, Delete and Tab as their symbols, side by side without a plus. Each symbol has its name as hidden text.

Everywhere else · platform="other"

The same keys as words, joined by a plus.

Looks

Sizes · size

Outline · outline

No fill; border and text take the surrounding text colour, so the keys work on any background, like this tooltip-style box.

Renamed keys · list-data

A JSON object from key name to label, for another language. The label is also what a screen reader hears for a symbol.
