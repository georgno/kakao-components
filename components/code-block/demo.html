Code block

<kakao-code-block> - preformatted text: a snippet, a config file, a command's output or a running log. Monospace in the theme's colours, scrolling past a maximum height, with an optional label row and a copy button (kakao-copy-button). The content is always shown as text. For a reference inside a sentence, such as src/app.js:42, there is kakao-code.

A snippet · label · language

The label row names the block (a file name, "Install") and shows the language, which is display only: there is no highlighting. The copy button sits at the end of the row and copies the whole text.

Install and test

npm install
npm test -- --watch

A config file

{
  "theme": "dark",
  "components": ["button", "code-block", "toast"],
  "vendor": { "dest": "public/kakao", "tag": "v0.10.0" }
}

Without a label row

No label and no language: the copy button sits in the top corner, and the text keeps clear of it. Markup can be indented with the page: the indentation all lines share is removed.

A command

git config core.hooksPath .githooks

Long lines · wrap

Long lines scroll sideways by default, so the columns of a table or a stack trace stay lined up. With wrap they wrap instead; good for prose-like output on a phone.

Height · max-height

Taller content scrolls inside the block (24rem by default). An overflowing block takes focus with Tab, so the arrow keys, Page Up / Down, Home and End can scroll it.

A longer file

(function () {
  'use strict';

  const TAG_NAME = 'kakao-toast';
  if (customElements.get(TAG_NAME)) return;

  const DEFAULT_DURATION = 5000;
  const MAX_VISIBLE = 4;

  class KakaoToast extends HTMLElement {
    static show(options) {
      const toast = document.createElement(TAG_NAME);
      Object.assign(toast, options);
      KakaoToast.region().append(toast);
      return toast;
    }

    static region() {
      let stack = document.querySelector('kakao-stack[data-toasts]');
      if (!stack) {
        stack = document.createElement('kakao-stack');
        stack.dataset.toasts = '';
        document.body.append(stack);
      }
      return stack;
    }
  }

  customElements.define(TAG_NAME, KakaoToast);
})();

A running log · mode="log"

A log follows its end while lines arrive. Scroll up to read: it keeps your place, also while old lines past max-lines are dropped above, and offers "Jump to latest". A carriage return rewrites the line (the progress counter), and ANSI colour codes are dropped.

Always text · text

Markup in the content is shown as text, never run: from the page (escaped, as any text), from text and from append(). Tags written into the element unescaped are parsed by the browser first, so only their text is left.
