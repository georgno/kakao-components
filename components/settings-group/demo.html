Settings group

<kakao-settings-group> with <kakao-setting> rows - the settings-screen layout: a titled group of rows, each with a label and hint on one side and its control on the other. The row names its control from the label. Narrow rows put the control under the label.

A settings screen

Real controls in the rows: a single switch (a switch group with one unlabelled item), a select, a text input, a number input and a slider. None of them has its own label; the row names it.

Security emails are always sent.

Links to subpages

With href the whole row is a link with a chevron; value shows the current choice before it. A leading icon goes in slot="icon".

Pro

Danger zone

variant="danger" colours the label. A row can hold a danger button, or with action be one button itself (it sends setting-action). Give a short button label a full aria-label.

In a card and in an accordion

Inside a kakao-card or kakao-accordion the group drops its own box: no second border, and the rows line up with the card's text.

Privacy

Narrow

Each row is a size container: below 30rem the control drops under the label and fields take the full width. Switches stay beside the label. layout="inline" or "stack" forces one layout.

Disabled

disabled dims the row's text and disables its control; a disabled link or action row does nothing.

<kakao-settings-group> attributes: heading, description, heading-level, variant (box, plain); slots: default (rows), title, description, footer. <kakao-setting> attributes: label, hint, href (+ target, rel), action, value, variant (danger), disabled, layout (auto, inline, stack); slots: default (the control), label, hint, icon. Event: setting-action. Full reference in the header of settings-group.js.
