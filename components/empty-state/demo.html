Empty state

<kakao-empty-state> - the quiet block shown where content is missing: an icon, a heading, a short message and actions, centred. It has no frame of its own and sits on the surface of the card, list or table area around it. For an error that fills the page there is the error page.

Heading and message

The heading is an h3 by default, because the block usually sits in a section or card that has its own heading; heading-level changes it. Content in the default slot replaces message, for text with a link.

Actions · slot="actions"

Buttons or links in a centred row that wraps; the main action first. Keep it to one or two.

Icon · slot="icon", no-icon

The built-in glyph is a tray. A slot="icon" child replaces it: an inline SVG in currentColor takes the icon colour and size. no-icon leaves the icon out. The icon is decoration, so give it aria-hidden="true".

Sizes · size="sm"

The default size is for a card or a panel. sm is for tight places: a table body, a popover, a small card. Smaller buttons go with it.

Where it sits

The block is as high as its content. In a table it goes in one cell across all columns; in an area with a height of its own, the area centres it (display: grid; place-items: center).
