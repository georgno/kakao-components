Pagination

<kakao-pagination> - page links for a long list: previous and next, the page numbers with an ellipsis window, and a compact “1–20 of 143” form it falls back to when it gets narrow. It stands alone; a table or grid puts one below itself.

Pages

The current page comes from page (1-based), the number of pages from total-pages, or from total-items and page-size. Without url the controls are buttons: the pager fires page-change and moves. A screen reader finds a navigation landmark, hears “Page 3” on each number and “current page” on the current one.

The ellipsis window

siblings is the number of pages on each side of the current one, boundaries the number always shown at the start and the end (both default to 1). The number of slots is the same on every page, so the pager keeps its width while paging; a gap that would hide one single page shows that page instead.

Real links

With url every control is an <a href>: {page} in the template becomes the page number, {page-size} the page size. A server-rendered page (Yii2’s ?page=2&per-page=20) pages without a script of its own, links open in a new tab, and previous and next carry rel. page-change still fires first; cancel it to stop the navigation and route it yourself.

Compact

The compact form is the summary with previous and next: “21–40 of 143” when the item count is known, “Page 2 of 8” from a page count. collapse="always" asks for it. By default (collapse="auto") a pager whose numbers do not fit its own width becomes compact by itself, so on a phone it never scrolls sideways; it goes by the element’s width, not the window’s. collapse="never" lets the numbers wrap instead.

Page size

page-sizes adds a “Rows per page” select. Picking a size fires a cancelable page-size-change with the new size and the page that keeps the first visible row in view; the pager takes both. It is a native select here, and a kakao-select on pages that load select.js.

    Sizes

    size follows the button heights: sm 36px, md 44px (default) and lg 52px, so a pager lines up with the buttons and fields beside it.

    States

    disabled keeps every control from being activated, for the moment rows are loading. hide-single renders nothing while there is only one page.

    One page · hide-single

    The first pager has one page and shows its controls unavailable; the second has hide-single and is not there.

    From script

    next(), previous(), first(), last() and goTo(page) move the pager and fire page-change with source: "api". Setting page, pageSize, totalItems or totalPages (or their attributes) is silent.

    Other words

    KakaoPagination.texts sets the words for every pager: the labels of the controls, range (“{from}–{to} of {total}”), pageOf, pageOnly, empty and pageSize. label names one pager’s landmark.
