Avatar

<kakao-avatar> - a person as a small round picture: the image when there is one, the initials of the name otherwise, an icon when there is no name. Optional status dot. <kakao-avatar-group> (same file) lays avatars over each other and counts the rest as "+N". Not interactive.

Image, initials, icon

The fallback order: the image, then an icon in slot="icon" if the page gave one, then the initials, then the built-in person glyph.

Image · src, name

The image loads lazily and fades in over the initials. name is its text alternative.

Initials · name

No image: the first letter of the first and of the last word. One word gives one letter.

Image that fails

The file does not exist: the initials stay, and an avatar-error event is sent.

Own initials · initials

Up to three characters, shown as written.

Icon · slot="icon"

Without a name: the person glyph, decorative. An own icon (inline SVG in currentColor) is shown instead of initials; the name still names the avatar.

Size and shape

Sizes · size

xs, sm, md (default), lg, xl. Initials, icon and dot scale with the avatar.

Rounded square · shape="square"

For things that are not people: teams, projects, bots.

Tone

From the name

The fill is one of five tones, picked from the name: the same name gets the same tone on every page. All tones are theme roles, tinted like the badge, so they follow the theme.

Chosen · tone

Status

Status dot · status

Online is filled, away half filled, busy carries a bar, offline is an empty ring: readable without colour. A screen reader hears "Ada Lovelace, Online".

Own wording · status-label

Looks the same; read as "Grace Hopper, In a meeting until 3".

Group

<kakao-avatar-group> overlaps its avatars and draws a ring in the surface colour around each. Its size and shape apply to all of them.

Stacked

Overflow · max

Six avatars, three shown: the rest is "+3", read as "3 more".

Only the first few on the page · total

The server sent three of 128 members; total makes the count right. Above 99 it shows "99+".

Group sizes and shape · size, shape

On another surface · --kakao-avatar-ring-color

The ring is the card colour by default. On another surface, set the ring colour to that surface.

Changing the group

Avatars added or removed later are counted again.

In context and events

Next to the name

The name is written beside it, so the avatar gets aria-hidden="true" and is not read twice.

As a link

The avatar never takes focus itself. In a link, its name becomes the link's name.

Events · avatar-load, avatar-error

Both bubble and cross shadow roots; the detail carries the src.
