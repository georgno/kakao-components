Skeleton

<kakao-skeleton> - a grey placeholder in the shape of content that is still loading, so the page keeps its layout until the content is there. Not interactive, and silent for screen readers. For a load without a shape use the spinner.

Text

Default

No attributes: one line of text, as wide as its place.

Lines · lines

With more than one line the last is shorter, like a paragraph.

Follows the font size

A line is measured in em and takes the room of a line of text, so it fits a heading as well as small print. width shortens it.

Circle and block

Circle · shape="circle"

For an avatar. width is the diameter; a number is pixels.

Block · shape="block"

A plain box, full width by default. Give it width and height, or a ratio so the height follows the width.

Corners · radius

A block has the field radius (10px). radius sets another: 0 for an image that bleeds to the edge, more for a large picture.

Put together

The plain shapes build any layout: here a circle next to two lines.

Presets

Two layouts that come up all the time are built in: list rows and a card.

List rows · shape="row"

A title and a line per row; avatar adds the circle, count repeats the row, lines sets the lines per row.

A card (shape="card") draws the card's frame with a title and three lines; media adds an image block on top, avatar a circle. The media block's corner is the card's radius minus its padding, at least the line radius (the nesting rule).

Animation

A light band moves across by default. With reduced motion switched on in the system, every skeleton stands still.

Shimmer, pulse, none · animation

Screen readers

Skeletons are decoration and say nothing. Announce the load once, on the region that is loading.

A loading region · aria-busy

The region carries aria-busy="true" while the skeletons are in it, and loses it when the content is in. A screen reader then waits with reading the region until it is ready.

A status of its own · label

Where no region can say it, one skeleton takes a label: it then carries a status with that text. Looks the same; a screen reader hears "Loading the article". Label one skeleton, not each.
