Tree view

<kakao-tree-view> - nested, collapsible rows: folders and files, or permission groups with checkboxes. One tab stop, arrow keys, type-ahead.

Nodes

Nodes come from list-data: { id, label, children, icon, expanded, disabled, selected }. By default one node can be selected (selection="single"). Click a chevron to open a node, click a row to select it; a double click on a row opens it too.

Folders and files · icon

Icons are named glyphs: folder, file, user, users, lock, key. Leave it out for none.

Labels only, with guides · guides

A node can be a plain string. guides draws a thin line down each open level.

From a nested list

Without list-data the tree reads a nested <ul> inside it, so a server can render the list and it stays readable when the script does not load. Items take data-id, data-icon, data-expanded, data-selected, data-disabled and data-lazy.

Selection

selection is single (default), multiple or none. With multiple every node has a checkbox: a parent ticks or clears everything under it and shows a dash while only some are ticked. With none the rows only open and close.

Permission groups · selection="multiple"

A disabled node keeps its state when its parent is ticked or cleared.

Rows that only open · selection="none"

A click anywhere on a row, Enter or Space opens and closes it.

In a form

With name the tree is a form control: every selected id is sent under that name (perm[] gives PHP and Yii2 an array). A fully ticked parent is sent along with its children; leaves-only sends only the nodes without children. A form reset brings back the initial selection.

Children that load later

"lazy": true marks a node whose children are not known yet. Opening it fires a cancelable tree-expand and shows a spinner until the page calls setChildren(id, nodes). Or set a loadChildren function that returns the nodes (or a Promise of them).

From script

expand(id), collapse(id), toggle(id), expandAll() and collapseAll() open and close nodes; nodes replaces the tree. They drive the first tree on this page.

Other words

KakaoTreeView.texts sets the words for every tree: label (the name when a tree has no label attribute) and loading (read out while a lazy node loads).
Attributes: list-data, selection, name, leaves-only, guides, label, disabled. Full reference in the header of tree-view.js.
