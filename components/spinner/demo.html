Spinner

<kakao-spinner> - a turning ring for a load of unknown length: the ring the button shows while it runs, on its own. Not interactive. For a load with a known amount use progress.

Ring

Default

No attributes: the button's ring at 18px in the surrounding text colour, announced as "Loading".

Sizes · size

Text colour

Without a tone the ring is drawn in currentColor, so it fits wherever text fits.

muted text primary text on ink

Tones · tone

A tone takes a theme role instead of the text colour.

Label

label says what is loading. A screen reader always gets it (the spinner is a role="status"); show-label also shows it.

Hidden label · label

Looks like the default; a screen reader hears "Loading invoices".

Visible label · show-label

The label keeps the text colour, also next to a toned ring.

Label below · stacked

For a panel that is still empty: a large ring in the middle, the label under it.

Delay

delay (milliseconds) keeps the spinner invisible and silent at first, so a load that finishes quickly never flashes one. It keeps its space meanwhile. The wait starts again each time hidden is removed.

Fast and slow loads · delay="400"

The fast load is done after 200 ms: no spinner. The slow one takes 2 seconds: the spinner appears after 400 ms.
