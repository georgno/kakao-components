Command palette

<kakao-command-palette> - a search over the page's actions. Press anywhere on this page, type a few letters, pick with the arrows and run with Enter.

Hotkey

The palette opens on hotkey (default Mod+K: Command on a Mac, Ctrl elsewhere), on open() and with the open attribute. Esc, the hotkey or a click on the covered page close it, and focus goes back where it was. In the palette: Up / Down, Home / End, PageUp / PageDown.

Groups, keywords, shortcuts and recent commands

Commands come from list-data: { id, label, group, keywords, shortcut, icon, href, value, disabled }. Try “nwf” (letters in order), “logout” (a keyword) or “théme” (accents are ignored). With recent, the commands you ran are listed first the next time.

Another key · hotkey

Any combination in kakao-kbd's notation: Mod+Shift+P, Alt+J, /, F1. A key without Ctrl, Meta or Alt is ignored while the user types in a field. hotkey="none" leaves only open(). Use one hotkey per page: every palette that has it reacts.

Running a command

command-select and href

Enter or a click runs the active command: the palette closes first, then fires command-select with { id, value, command }. A command with href then goes there; preventDefault() stops that. Here the event is cancelled, so the links stay on this page.

From script

commands, open(query) and icons

commands sets the list as an array; open(query) opens with text already in the field. icon is inline SVG markup in currentColor (scripts and event attributes are removed).

Inline

Shown in place · inline

For previews and help pages: always open, no scrim and no hotkey. Esc clears the field.
Attributes: list-data, hotkey, recent, label, placeholder, empty-text, no-hints, inline, open. Full reference in the header of command-palette.js.
