Plain list

<kakao-plain-list> - a plain list of short items: file:line references, test names, findings. It wraps a <ul> or <ol> and gives it even gaps, muted markers and long paths that wrap on a phone. Items can start with a badge or an icon: the leads then line up in one column. It is light DOM: plain-list.css draws it, so a server-rendered list needs no script. Not the list, which is a 3D picker.

Leading badges

When every item starts with a kakao-badge, the badges form one column as wide as the widest, and the text starts at the same place in every row. A name that wraps stays in its column.

Leading icons

An <i class="…"> icon works the same way. A decorative icon gets aria-hidden="true"; wrap an <svg> or <img> in <span data-lead>.
