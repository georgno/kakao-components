Section header

<kakao-section-header> - the heading row of a page section: a real heading (level 2 to 6), an optional count or count badge, a muted line of description and actions at the end of the row, which wrap below the text on a phone. It is light DOM: the heading is rendered into the page itself, so it belongs to the page's outline, a table of contents lists it and #id links reach it. Load section-header.css with the script.

Heading, count, description, actions

The common case. The count sits in the heading (read as "Findings 12") in the muted colour; the actions are children with slot="actions". Make the window narrow: the actions move below the text.

A report section

Count badge

count-tone draws the count as a kakao-badge of that tone (load badge.js). count-label is what a screen reader hears instead of the bare number: "Failed tests, 3 failed".

Levels

level picks the heading element, h2 (default) to h6; pick the one that fits the page's outline (h1 is the page title). The size follows: h4 to h6 look alike.
