Menu

<kakao-menu> - a menu of actions, opened from any trigger or as a context menu on right-click. Groups, separators, icons, shortcuts, check and radio items, links and submenus. For a simple pick-one dropdown, <kakao-button list-data> is enough.

From a trigger

for names the trigger by id. A click opens and closes the menu; Down or Up on the trigger opens it on the first or last item. In the menu: arrows, Home / End, a letter to jump, Enter to pick, Esc to close.

Icons, shortcuts, a separator and a danger item

Items come from list-data: { label, value, icon, shortcut, disabled, tone }; "-" is a separator. Shortcuts are drawn by <kakao-kbd> when it is loaded, else as plain text. They are hints: the menu does not bind the keys.

Labels only

An item can be a plain string; its value is then the label. Any element can be the trigger.

Sort by

Placement · placement

bottom-start (default), bottom-end, top-start or top-end. The menu flips to the other side when there is no room, and always stays inside the viewport.

Groups

Headings · { group, items }

A group puts a heading over its items and is announced with it. Leave the heading out for a group without one.

Check and radio items

type: "checkbox" and type: "radio" · keep-open

A checkbox item turns on and off; of the radio items in one group, one is on. menu-select reports the new state as checked. With keep-open these items do not close the menu.

Submenus

children

An item with children opens a submenu: on hover, on click, with Right or Enter. Left or Esc goes back. It opens to the right, else to the left; with room on neither side (a phone) it opens under its item.

Links

href

An item with href is a real link (with optional target), so it can be opened in a new tab.

Context menu

context-for names an element whose context menu this is. It opens at the pointer on right-click, on a long press on touch, and under the focused element with Shift+F10 or the Menu key.

An area · context-for

Right-click, long-press, or focus and press Shift+F10

One menu for several rows

The context element can be a list: menu-open is the moment to note which row the menu is for.

From script

open(anchor), openAt(x, y), close(), items

Without for the menu is opened by script: against any element, or at a point in the viewport. items sets the entries as an array. Cancel menu-select to keep the menu open.

Inline

Always shown · inline

The menu sits in the page, one tab stop with the same keys. Submenus still open beside it.
Attributes: list-data, for, context-for, placement, label, keep-open, inline, disabled, open. Full reference in the header of menu.js.
