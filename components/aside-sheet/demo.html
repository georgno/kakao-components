Aside sheet

<kakao-aside-sheet> - a card that slides in from an edge of the viewport. Modal by default, built like the dialog: a plain fixed overlay, so it behaves the same on phones, tablets and desktops. Only the corners facing into the page are rounded. Shadow DOM, slots for header, body and footer.

Four sides

Each button opens its sheet through the sheet's for attribute: no script. Escape, a click on the covered page or the close button ends it, and focus goes back to the button.

Variants

Long body · handle

Header and footer stay put; only the body scrolls. Drag the handle or the header down to close.

Form in the footer

A comment field that stays above the scrolling thread.

Non-modal · modal="false"

No scrim, no focus trap, no scroll lock: the page stays usable behind it.

Cancelable close · sheet-hide

Type something, then try to close: a dialog asks first and opens over the sheet.

no-dismiss

Escape, the scrim and the close button do nothing; only the footer buttons end it.

Right to left · side="end"

Inside dir="rtl" the end side is the left edge.

End side, right to left

This sheet sits inside an element with dir="rtl", so side="end" attaches it to the left edge and its rounded corners face right.

Playground

Every sheet reports sheet-show, the cancelable sheet-hide and sheet-hidden (after the slide out), with the reason and the data-close value.

Attributes: open, side (bottom · top · start · end; left · right), for, label, modal="false", no-dismiss, no-close-button, close-label, handle, contained. Methods: show(), hide(returnValue), toggle(), isOpen. Slots: header, default (body), footer. Full reference in the header of aside-sheet.js.
