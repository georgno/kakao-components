Copy button

<kakao-copy-button> - copies a text to the clipboard and confirms it: a check and "Copied", also for screen readers, then back to a copy button. Says so when the browser refuses.

What it copies

A text · value

Without a label the button is icon only and is named "Copy"; aria-label says what is copied.

Another element's text · for

The id of the element to copy from, read when the button is clicked.

npm install kakao-components

A field's value · for

For a field (native or a kakao input) it is the current value: change the text, then copy.

Looks

Variants · variant

Secondary (default) and ghost, the two quiet looks of the button.

Sizes · size

The button's three heights, here next to a button of each size.

Own icon · slot="icon"

Replaces the copy glyph. The check and the failure mark stay the component's own.

Disabled · disabled

Confirmation

Own words · copied-label, error-label

Shown in place of the label and announced to screen readers. The button is as wide as the longer of label and copied label, so confirming does not change its size.

How long it stays · reset-delay

Milliseconds until the button is a copy button again: 1600 by default, here 4000. With 0 it stays until reset() is called.

When it fails

Nothing to copy (no value, or the for element is missing or empty) or the browser refuses: a cross, "Copy failed", and a copy-error event with the reason.

Events and in context

Events · copy-success, copy-error

Both bubble and cross shadow roots; the detail carries the text and, on failure, the reason.
