Breadcrumb

<kakao-breadcrumb> - where the current page sits, built from title/url pairs. It starts with a home item and ends with the current page.

Start item

A house icon by default (screen readers hear the start text). start="text" shows the text, start="none" leaves it out.

The start text is a constant

KakaoBreadcrumb.startText sets it for every breadcrumb at once (default START_TEXT, "Start"); start-text sets it for one.

Long trails

The trail wraps; a very long title is cut off with an ellipsis and shows in full on hover.

Single-page apps

Every link fires a cancelable breadcrumb-navigate. This one is cancelled, so the page stays and the log shows what an app would route to.
