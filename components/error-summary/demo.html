Error summary

<kakao-error-summary> - the list of a form's errors at the top of the form, each one a link to its field. It replaces the browser's error bubbles: on submit it lists every invalid field, native or kakao, and takes focus so a screen reader reads it out. A link moves focus to the field and scrolls it into view below the header bar.

A form · inside it

Submit the empty form. The summary lists the kakao text inputs, select, date input and checkbox (through their ElementInternals validity) and the native email field, number input and radio group (through the browser's). With live, a line goes away as soon as its field is fixed.

All fields are valid. (The demo stops the submit here.)

Linked with for · server errors with show()

A summary outside the form names it with for. A kakao field that comes back from the server with an error attribute counts as invalid with that text. Errors the page knows itself go in with show([{ field, message }]); a line without a field has no link. clear() empties it.

Around the form · heading · description

The summary can also wrap its form; the form is its default slot and sits below the box. slot="description" adds a line between the title and the list.
