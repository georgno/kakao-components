Tag input

<kakao-tag-input> - Free text that becomes tags: type and press Enter or a comma, paste “a, b, c” to add several. The tags are <kakao-chip>s that wrap inside the text input's field. Backspace in the empty field selects the last tag, a second Backspace removes it; ← / → move between tags. Form-associated: one form entry per tag.
