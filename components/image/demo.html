Image

<kakao-image> - an image that keeps its place while it loads: a skeleton of its size until the file is there, then the picture fades in. Loads lazily, takes the alt text and an optional caption. Not interactive. Load skeleton.js with it; without it the placeholder is a plain still block.

Image, alt text, caption

Image · src, alt

alt says what the picture shows, for people who cannot see it. width and height are the size of the file, as on <img>: the space is reserved, and the image scales down with its place.

Caption · caption

The text below the image. With a caption the whole is a figure with a figcaption; the caption is as wide as the image.

Caption with markup · slot="caption"

Content in the slot replaces the attribute, for a link or a credit.

The valley in the morning. Picture: demo images

Decorative · alt=""

An image that adds nothing to the text around it gets an empty alt: assistive technology skips it. Every image that carries meaning needs a real text.

Reserving the space

Say how large the image will be, and the page does not jump when it arrives: either width and height, or a ratio.

Ratio · ratio

The frame is as wide as its place (or as width) and takes its height from the ratio. The image fills it.

Width and height · width, height

A number is pixels, anything else a CSS length. Two numbers give the ratio and scale down together; a CSS height stays as it is.

No size given

Without height and ratio the skeleton has a fixed height (12rem), and the image then takes its own size. The content below moves, so give a size where you know it.

Fit and corners

Cover and contain · fit

A tall picture in a wide frame. cover (default) fills the frame and cuts the rest; contain shows the whole picture. The free space is transparent unless --kakao-image-background is set, as here.

Corners · radius

The default is the field radius (10px). 0 for an image that bleeds to the edge, more for a large picture, 999 with a ratio of 1 for a circle.

Loading

The image loads when it comes near the viewport (loading="lazy", the default). Until the file is there the frame shows a skeleton; the picture then fades in over it. With reduced motion switched on in the system there is no fade and the skeleton stands still.

A slow image

These files load at once, so the skeleton is hardly seen. The button takes the src away and sets it again two seconds later: an image without src waits as a skeleton.

At once · loading="eager"

For the image at the top of a page, which should not wait for the viewport check.

Several files · srcset, sizes

Both are passed on to the <img>, so the browser picks the file for the screen. (The demo names the same file twice.)

When the image fails

Error state

The file does not exist: the frame keeps its size and shows a muted icon with the alt text. A decorative image (alt="") shows the icon only. The caption stays.

Events and reload() · image-load, image-error

Both events bubble and cross shadow roots; the detail carries the src, and on a load the file's own size. reload() tries again, state says where the image is.
