Error page

<kakao-error-page> - an error page drawn from a few attributes: the status code very large and as a diagonal pattern in the background, the error's heading, a message, reference information for support and the page's actions. Embedded in a box by default, or filling the viewport with full.

Code, heading, message

Common codes come with an English heading; heading sets your own. The code is part of the heading, so a screen reader hears "Error 404: Page not found". The heading is an h1 (the error is the page's main content); heading-level changes it when the error page sits inside other content, as on this page.

Reference information · reference, time, list-data

Muted label/value rows under the message. One click selects the whole reference, ready to paste into a support request. An ISO time is shown in the page's language; any other text is shown as written. list-data adds rows as [label, value] pairs.

Actions and details · slot="actions", slot="details"

Actions sit in a centred row that wraps; the main action first. Details take longer content below, aligned to the start.

Embedded or full · full

Embedded (the default) is a framed box with a minimum height, for a panel or a card. full drops the frame, sits on the page background and fills the viewport height below the header bar (--kakao-error-page-full-height; here the frame sets it to 26rem).
