Dialog

<kakao-dialog> — a modal that covers the page and keeps focus inside. Built on a plain fixed overlay rather than <dialog> and showModal(), so it looks and behaves the same on phones, tablets and desktops. Shadow DOM, slots for header, body and footer.

Try it

The page behind scrolls normally while the dialog is closed and is locked while one is open. Escape or a click on the covered page closes it, and focus goes back to the button that opened it.

Variants

No header · label only

The label attribute names the dialog when there is no header element.

Sizes · size="sm" | "lg"

Taller than the screen

Header and footer stay put; only the body scrolls.

Playground

Every open and close bubbles as dialog-open / dialog-close; data-close decides the return value.

Attributes: open, label, size (sm · md · lg), no-dismiss. Methods: open(), close(returnValue), toggle(), isOpen. Slots: header, default (body), footer. Full reference in the header of dialog.js.
