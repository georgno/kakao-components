Tooltip

<kakao-tooltip> - a small themed label next to a control: the name of an icon-only button, or a short hint. It shows on hover, on keyboard focus and on a touch long-press, so it also reaches people on a phone, where the native title never shows.

Buttons

Icon-only buttons · automatic

Nothing to add: with tooltip.js loaded, an icon-only kakao-button shows its name. Hover, tab onto them, or press and hold on a touch screen. Without the script they keep the native title.

Touch · long-press

On a touch screen, a tap runs the action as usual. Press and hold for half a second to read the name instead: the action does not run, the menu does not open and no context menu or text selection appears. Moving the finger or scrolling cancels it; the label goes on the next tap, on scroll or after three seconds.

A hint as well as the name · data-tooltip

On the host, data-tooltip replaces the label text, also on a button with a visible label. When it differs from the name, the button is described by it (aria-describedby) while it shows; the name stays as it is.

Turned off · title=""

An empty title (or data-tooltip="") on the host turns the tooltip off, with or without the script. Use it when the icon is plain enough and the name is already said next to it.

Any element

By attribute · data-tooltip

Any element can opt in with plain text. Give a non-interactive one tabindex="0" so keyboard users can reach it too.

Invoices are sent as PDF files. Read the terms of payment before you pay.

Dedicated element · for

A <kakao-tooltip> with for belongs to one element; its text is the label and describes the element. hidden only keeps the text out of sight before the script runs.

Placement · data-tooltip-placement

top (default), bottom, left or right; on a kakao-tooltip it is placement. It flips to the other side when there is no room and stays inside the window.

Script

Events and API

tooltip-show and tooltip-hide bubble from the anchor with { text, reason } (hover, focus, touch or api). KakaoTooltip.show(anchor, text) shows a label from script, for example a confirmation.
