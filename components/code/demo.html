Inline code

<kakao-code> - code inside a sentence: a file:line reference, a command, a setting name. Monospace on a tinted fill, in the colour of the text around it. It is light DOM: code.css draws it, so a server-rendered page looks right before any script runs. For several lines or a log there is the code block; for keyboard keys, kbd.

In running text

File and line, a command, a name: each reads as part of its sentence.
