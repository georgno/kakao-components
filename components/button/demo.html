Button

<kakao-button> - button with variants, sizes, icons, toggle state and an async loading → success/fail animation via run(promise). Light DOM: load button.css next to the script.

Variants

variant: primary (default), secondary, ghost, danger.

Sizes & icons

size: sm, md, lg. icon-position: left, right, only (inferred when no label). An icon is a child with slot="icon" (first row): an inline SVG needs nothing else; an icon-font element such as the gear works too when the page loads that font. The icon attribute is an optional shortcut for icon-font classes (second row); it also needs the font, which is why this site loads Font Awesome.

Menu

list-data turns any variant into a dropdown button: a chevron and a menu of choices. selected marks the current one; show-selected puts it on the button; no-chevron hides the chevron (icon-only dropdowns then stay round). Keyboard: ↓ / ↑ open, arrows move, a letter jumps, Enter picks, Escape closes.

Playground

run() wires a promise to the loading animation; it resolves to a check, rejects back to the label.
Attributes: label, icon, icon-position, variant, size, disabled, toggle, pressed, type, name, value, form, href, aria-label. data-* is mirrored onto the inner button. Menu form: list-data, selected, show-selected, no-chevron. Events kakao-button-action, kakao-button-select, kakao-button-menu.
