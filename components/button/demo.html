Button

<kakao-button> — button with variants, sizes, icons, toggle state and an async loading → success/fail animation via run(promise). Light DOM: load button.css next to the script.

Variants

variant: primary (default), secondary, ghost, danger.

Sizes & icons

size: sm, md, lg. icon-position: left, right, only (inferred when no label).

Sizes

Icons

Toggle

toggle flips pressed on click. Inside .kakao-button-segment they look like a segmented control.

Single toggle

Segment (exclusive)

Playground

run() wires a promise to the loading animation; it resolves to a check, rejects back to the label.

Attributes: label, icon, icon-position, variant, size, disabled, toggle, pressed, type, name, value, form, href, aria-label. data-* is mirrored onto the inner button. Event kakao-button-action.
