## MODIFIED Requirements

### Requirement: One stylesheet
`shared/kakao.css` SHALL hold `shared/tokens.css`, `shared/font.css`, `shared/themes.css` and `shared/base.css`, in that order, unchanged, so a page can load tokens, font, themes and the page base with one link. Every rule in base.css SHALL be wrapped in `:where()` so page CSS wins without `!important`. It SHALL be generated by `node tools/loader.js` and never edited by hand.

#### Scenario: A token changes
- **WHEN** a value in shared/tokens.css changes and kakao.css is not regenerated
- **THEN** `node tools/loader.js --check` exits with code 1 and names kakao.css

#### Scenario: A page sets its own body font
- **WHEN** a page with kakao.css has `body { font-family: serif }`
- **THEN** the page's rule wins over the base
