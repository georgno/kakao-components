# Spec Delta

## ADDED Requirements

### Requirement: Touch steppers
On touch screens or with `touch-steppers`, the steppers SHALL stay on the right as − and + buttons side by side, each at least 44px, with the field at least 44px tall and 16px text. Holding a stepper SHALL repeat the step for every pointer type.

#### Scenario: Touch layout
- **WHEN** a number input is shown on a phone
- **THEN** it reads | value | − | + | with 44px buttons
